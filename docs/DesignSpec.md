# GoReadwise Design Spec

审美方向：**墨水天文台 / Dark Academia Observatory**。不是通用紫渐变仪表盘，而是深夜书斋里的星图桌：墨蓝底、琥珀金、羊皮纸字色、细密噪点与星尘。

## 调色

| Token | 值 | 用途 |
|---|---|---|
| `--ink` | `#070b14` | 主背景 |
| `--ink-2` | `#10182a` | 侧栏 / 面板 |
| `--ink-3` | `#1a2438` | 悬浮层 |
| `--line` | `#2a354d` | 分割线 |
| `--gold` | `#d4a053` | 主强调、双链、CTA |
| `--gold-dim` | `#8a6a32` | 弱强调 |
| `--parchment` | `#e8dcc8` | 主文字 |
| `--mist` | `#8b93a7` | 次级文字 |
| `--rose` | `#d36b6b` | 悬空链接 / 危险 |
| `--teal` | `#6bb3b0` | 标签 / 成功 |

## 字体

- 展示：`Fraunces`（卡片标题、品牌）
- 界面：`Source Serif 4` 不采用；改 `IBM Plex Sans`
- 编辑器：`IBM Plex Mono`

禁止 Inter / Roboto / Space Grotesk / 通用紫渐变。

## 布局

- 桌面：左抽屉（卡片/标签）+ 三栏编辑器，或全屏星空图。
- 768px：隐藏侧栏为抽屉；三栏改为上下堆叠（编辑 / 预览 / 反链）。
- 480px：单栏，预览与反链用分段切换。

## 组件

- 按钮有 hover 金边与轻微上升，禁用态降低透明度。
- Toast 可手动关闭，5 秒自动消失。
- 删除必须确认 Modal，禁止 `alert`。
- 表单错误在字段下方红字。
- 空态：星尘插画文案，而不是空白页。
- 加载：骨架星点闪烁。

## 图视图

- 实心琥珀节点 = 真实卡片；半透明虚线 = 幽灵节点。
- 节点半径随度数映射。
- 一级标签决定色相偏移。
- 点击节点：Quick Edit 浮层，不是嵌套三栏。
