基于Go语言帮我实现一个极客学术与个人技术文献/知识剪藏卡片箱（类似 Readwise + Obsidian 核心）

业务背景：专门为开发者和深度学习者设计的全栈卡片箱管理系统（Zettelkasten 原理）。支持网页剪藏、多级标签关联、卡片间的"双向链接"，并在前端提供可视化的知识网络。

前端页面 (Vue 3 / Svelte + Cytoscape.js)：双栏/三栏卡片编辑器：左侧编辑 Markdown，中间实时渲染，右侧显示引用了当前卡片的"双向链接"列表。知识星空图（Graph View）：将每张卡片渲染为一个节点，如果卡片 A 引用了卡片 B，则连成一条线。支持在前端拖拽、点击节点直接开窗编辑。

Go 后端核心实现：Markdown 双链解析引擎：手写或扩展正则解析器，识别文本中的 [[卡片名称]] 语法，在后端自动建立并维护"正向引用"与"反向链接（Backlink）"的关系表。卡片关系动态提取：当卡片内容被修改时，Go 异步启动协程，动态计算该卡片关联线段的增删，实时更新图结构数据。

文件数与代码量：约 25~35 个 Go 文件，代码量 5500 - 8000 行。
